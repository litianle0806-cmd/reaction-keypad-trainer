# 反应力 × 小键盘 训练场

把 [FYTester](https://www.fytester.com/) 的反应力测试和 [在线小键盘练习](https://yoqo.github.io/game/keypad/) 的功能整合到一个本地页面，纯静态、无需联网、数据只存本地。

## 打开方式

直接双击 `index.html` 即可，或者在目录里起一个本地服务：

```bash
cd "反应力与小键盘训练"
python3 -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000
```

## 功能

### 反应力测试

三种模式：

- **单次** — 一次一个刺激，最纯粹的反应测量
- **连续 5 次** — 去掉单次偶然性，看平均值
- **选择反应** — 绿色立刻按、红色忍住别按，练「看对了再出手」，误按会单独计数

反应方式**可以随时切换**，不用重新开始：

- 🖱️ **鼠标点击** — 点测试区域任意位置
- ⌨️ **Enter 键** — 按回车

同一套测试里两种方式的成绩分开记录，因为键鼠延迟本来就不一样（键盘通常比鼠标快）。抢跑算作废，需要重新点一次。

结果会给平均值、最快单轮、轮数和评级（D → SSS），并保存最近 30 次画成趋势柱状图。

### 连击测试

测一定时间内能连按多少次 Enter，用来练手指的回弹速度和节奏感。

- 按 Enter 开始（3-2-1 倒计时），倒计时结束后才开始计数
- 时长可选：1 秒（默认）、3、5、10 秒
- 结算给出每秒连击数、总次数、最短按键间隔和评级（D → SSS）
- 各时长的最佳成绩分别记录

**按住不放不会刷次数**：长按产生的自动重复事件会被过滤，每次都必须真实按下并松开。鼠标点击只用来开始，计数阶段只认 Enter，避免两种输入混算。

### 小键盘练习

- 按 <kbd>Enter</kbd> 或点 START 开始，3-2-1 倒计时后进入练习
- **同一时间只显示当前这一组**，整行 62px 大字号连续排列，不用在多个小组之间来回找
- 数字用等宽字体并启用斜杠零（`0`），避免和 `8` 看混
- 数字串按组出现，用数字小键盘（或主键盘数字排）录入
- 录错**不能回改**，跟真实录入考试一样
- 每组位数可选：随机 6–20 位 / 固定 6、8、10、12 位
- 时长可选：1、2、3（默认）、5 分钟
- 右侧「最近练习」保留最近 6 次成绩，可单独清空

实时统计已录入、对错数、完成组数、速度（键/分）、KPH、正确率和综合评分（`速度 × 正确率`）。结束后给出评级：见习 → 新手 → 入门 → 熟练（约 130 分，常见岗位达标线）→ 高手 → 键圣。

切到别的标签页会自动暂停，回来后可以继续或者放弃本轮重新设置。

### 我的记录

两个模块的历史成绩表，可分别清空。所有数据都存在浏览器 localStorage 里，不上传服务器。

## 文件结构

```
index.html        页面结构
css/style.css     样式（深色主题、响应式）
js/app.js         全部逻辑（无依赖，原生 JS）
```

## 实现说明

- 计时用 `performance.now()`，毫秒精度
- 小键盘练习的结算速度按**设定时长**封顶，避免切后台时浏览器节流定时器导致成绩被压低
- 页面隐藏（切换窗口）时自动中止反应测试、暂停小键盘练习
